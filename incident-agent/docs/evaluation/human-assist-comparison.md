# 人工辅助排障对照（方案，待确认）

日期：2026-11-04。对应[任务 0014](../../tasks/0014-assist-and-evidence.md)，补上[评测方案](plan.md)第 8 节一直没有做的业务效率对照。尚未执行，下面的判定标准要在开始前确认并提交。

## 要回答的问题

人拿到 Agent 的报告后，能不能更快、更有依据地继续排查？根因命中率继续记录，但不决定这个问题。

## 怎么比

| 组 | 工具 |
| --- | --- |
| 对照 | Jaeger、Loki、Prometheus |
| 实验 | 同样的工具，加 Agent 报告（混合流程） |

- **场景：** 隔离会话新出 4 至 6 个没见过的场景，冻结遥测，真值由它保管。
- **参与者：** 至少 2 人更有意义。只有 1 人时结论只算观察，不算比较。
- **避免记住答案：** 同一个人不做同一道题的两组。每人一半场景用工具，一半用工具加 Agent，顺序交替。
- **环境：** 只读，遥测窗口和冻结样本一致，时间上限每题 20 分钟，到时记录当时的结论。

## 记录什么

| 关注点 | 怎么衡量 |
| --- | --- |
| 是否节省时间 | 从开始到确认关键线索、确定有效下一步的时间，包括阅读、等待和核查报告的时间 |
| 是否减少重复工作 | 查询次数、跨工具切换次数、手工关联的步骤 |
| 是否造成误导 | 是否因报告去了错误组件、相信了不存在的事实，纠正花了多久 |
| 是否保留诊断质量 | 最终结论和下一步检查是否有依据；根因是否命中 |

每道题结束后，真值保管方判定“关键线索”和“有效下一步”，这两个定义要在开始前按场景写好。

## 判定标准（待确认）

实验组全部满足才算有帮助：

1. 到达关键线索的中位时间明显缩短。样本太少，只看方向，同时报告逐题差异。
2. 没有一道题因为报告走错方向后没能纠正。
3. 最终结论的依据不比对照组差。

## 不能得出的结论

人数和场景都很少，只能说明方向，不能外推到生产，也不能换算成节省的人力成本。

## 需要确认

- 谁来当参与者，能投入多少时间。
- 是否接受只有 1 人时的观察性结果。
