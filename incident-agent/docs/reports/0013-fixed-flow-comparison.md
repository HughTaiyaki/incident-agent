# 任务 0013 第 1 阶段：动态 Agent 和固定流程对照

日期：2026-11-03。对应[任务 0013](../../tasks/0013-evidence-and-baseline.md)，规则在运行前写入[预先写定](../evaluation/0013-preregistration.md)（提交 `18b650f`）。判分人 Claude，隐藏流程标签，但知道场景真值，所以不是盲测。用户抽检尚未完成。

## 结论

**按写定的规则，动态调查没有达到保留标准：** 动态 Agent 命中 22/25 份样本，固定流程 20/25，只多 2 份，没到 3 份。规则对应的结果是默认用固定采集，只在证据缺口明确时启动动态补查。

这个结论很接近，而且有一处规则没反映出来：固定流程的 N1 全部算判对，但它一次也没看到 1062 错误，见[下文](#规则没有反映的地方)。

## 结果

每种流程 75 次，共 150 次。接口全程健康，没有模型调用失败，没有空报告。

| 指标 | 动态 Agent | 固定流程 |
| --- | --- | --- |
| **命中样本（3 次至少 2 次判对）** | **22/25** | **20/25** |
| 故障和 bug 场景判对 | 39/48 | 33/48 |
| 其中 D1+D3 | 18/18 | 15/18 |
| 正常场景没有误判 | 18/18 | 18/18 |
| N2 没有给出 DIAGNOSED | 9/9 | 9/9 |
| 无依据断言（因果或数字） | 3/66 | 3/66 |

| 耗时中位数 | 9.4 秒 | 5.7 秒 |

全部费用约 ¥1.64（含接口探测），按 Token 比例估算动态 Agent 约占 72%。

**只有两份样本结果不同，都是动态 Agent 更好：**

| 样本 | 动态 Agent | 固定流程 | 原因 |
| --- | --- | --- | --- |
| H3（付款和关单竞争） | 3/3 | 0/3 | 固定流程没看到“付款晚于关单、已安排退款”的记录 |
| D1 的 1 份样本 | 3/3 | 0/3 | 固定流程没有说出“预留结果未知” |

其余 23 份样本，两种流程判对的次数相同。

## 未判对的运行归类

| 类别 | 动态 Agent | 固定流程 | 场景 |
| --- | --- | --- | --- |
| 证据不足 | 6 | 6 | H2、B1：冻结样本里没有崩溃或重复扣减的直接记录 |
| 检索失败 | 1 | 6 | 固定流程的 D1、H3；动态 Agent 的 B7 |
| 解释错误 | 2 | 3 | B7 |
| 运行失败 | 0 | 0 | |
| 合计 | 9 | 15 | |

这说明三件事：

- **H2、B1 换哪种流程都没用：** 问题出在数据，不在查询方式。
- **B7 的主要问题是解释：** 两种流程都 0/6。关键记录大多展示过了，模型还是没说出 goods 太慢。只有 1 次把因果说反，比第四次复测少。
- **固定流程的损失集中在检索：** 这正是“证据缺口明确时再动态补查”想解决的问题，但缺口如何判断还没有设计。

## 规则没有反映的地方

**N1 的判对标准太松。** 动态 Agent 9 次都看到了 1062 错误，固定流程 0 次。固定流程的 9 次都没提到并发重复提交，其中 4 次还写了“没有记录到错误”，这个说法是错的，样本里有这条记录。结论“不是技术故障”碰巧对了，原因并不对。

如果把 N1 改成必须说出并发重复提交，差距会变成 5 份，动态调查就能保留。这是看到结果后才想到的口径，**不能据此改决定**，只作为你判断时的参考。它也提醒第 4 阶段要定更严的正常场景标准。

## 不能外推

- **样本和提示词都调优过：** 这组对比只回答动态查询有没有增益，不代表泛化能力。
- **样本少：** 差距来自 2 份样本，换一批样本可能不同。阈值 3 是经验值，不是显著性检验。
- **重试名额没有被实测：** 这次接口健康，没有发生失败，报告调用的重试只有单元测试覆盖。
- **成本比较只在这个规模成立：** 这里只有 5 个服务，固定流程查 9 次够用。服务变多后，固定扫描的成本和遗漏都可能变化。

## 对第四次复测的更正

[第四次复测](0012-fixed-fault-evaluation.md#第四次复测harness-v14)把 N1 的“沿用了已有订单”记为 3 条没有记录支持的断言。这次核对发现，N1 样本里的并发 CreateOrder Span 状态都是 0，这对“重复提交也拿到了成功响应”有支持，只是没有直接写出沿用已有订单。所以这次不再把它算作无依据，第四次复测的严格口径 13.3% 也偏高，去掉这 3 条后是 8.3%。
