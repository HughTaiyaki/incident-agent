# 任务 0003：离线单次调查闭环

状态：**本切片完成（2026-10-29）**。用户要求暂不修改商城，继续 Agent 开发；据此先实现不依赖上游变更的执行内核。任务 0002 的固定版本故障样本继续待验收，不标为完成。

## 范围与实施顺序

1. 消费方定义 Decider/Querier，单 Run 顺序执行 query/report 决策；输入范围冻结，参数校验先于查询。
2. 实现 12 次决策（最后一次只允许报告）、16 次实际后端请求、同查询最多两次、连续三次无新记录转汇总、180s 截止、取消和确定性收尾。当前脚本决策没有模型 Token 消耗；模型预算与 Provider 后续实现。
3. 保存本 Run 的冻结查询结果；Report Guard 校验引用、时间线和结构，最多一次报告修正；恢复判断本切片只接受 UNKNOWN。
4. 提供仅离线的 incident-investigate CLI，读取已有 Bundle 和脚本决策，输出报告、证据与决策审计；不把脚本决策称作模型诊断。
5. 验证越界、伪造引用、无进展、重复、超限、取消、来源失败、容量和快照隔离，并以真实历史 Bundle 跑通。

## 验收

- [x] 查询越界或决策非法时不调用 Querier；仍消耗决策次数。
- [x] 失败与无进展有界；重复采集时间不算新事实；取消不继续查询。
- [x] 报告引用只能来自本 Run；未知来源与证据缺口独立保留。
- [x] 离线 CLI 无网络，输出不覆盖，退出状态区分执行完成与取消/错误。
- [x] 单元、race、lint、构建与离线样本验证通过，文档入口同步。

## 边界与后续

不修改商城代码、配置或运行服务；必要的上游调整先向用户说明并提醒审查。不启用真实模型、Token 预算、Redis、恢复/租约、HTTP 调查接口、SSE 或诊断成绩评测。内存 Run 的落盘产物仅用于核查，不支持恢复执行。后续接入模型前须补输入压缩、Token 预留及真实样本效果评测。
